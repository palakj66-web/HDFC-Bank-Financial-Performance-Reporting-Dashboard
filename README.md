## 📌 Executive Summary
This project delivers an interactive executive financial dashboard tracking the performance of **HDFC Bank Limited** across five fiscal years (**FY22 through FY26**). 

Sourced from historical disclosures via **Screener.in**, the dataset was structured into a synchronized dual-view model in Tableau Desktop. Decision-makers can toggle between Profit & Loss, Balance Sheet, and Cash Flow metrics via a centralized parameter control to monitor core banking health, revenue growth, and balance sheet scale.

---

## 🔑 Technical Highlights & Architecture

- **Synchronized Dual-View Layout:** Seamlessly pairs a structured line-item financial statement table with continuous 5-year trendline charts.
- **Unified Parameter Selector:** A single dynamic Parameter control allows users to switch between **P&L (Income Statement)**, **Balance Sheet**, and **Cash Flow**. Updating the parameter instantly re-renders both the data table and the trend curves in parallel.
- **Line-End UX Labeling:** Configured data labels strictly to **Line Ends (FY26)**. This isolates the latest closing figures in Crores (₹ Cr) while eliminating visual noise across multi-line historical trajectories.
- **Responsive Screen Adaptation:** Configured dashboard canvas to **Automatic** sizing to ensure layout responsiveness across monitors, laptops, and executive briefing displays.

---

## 📈 Banking Metrics & Analysis
1. **P&L Performance:** Evaluates Interest Income, Financing Expenses, Net Interest Income (NII), and Net Profit margins over the 5-year cycle.
2. **Balance Sheet Scaling:** Tracks growth in customer deposits, total advances (loan book expansion), and shareholder equity reserves post-merger.
3. **Cash Flow & Liquidity:** Visualizes operating cash flows, investment activities, and liquidity coverage over time.

## 📚 Key Learnings & Takeaways

- **Banking Financial Analysis:** Gained exposure to interpreting HDFC Bank's financial statements, including profitability, balance sheet movements, and cash flow trends across multiple financial years.

- **Parameter-Driven Interactivity:** Gained practical experience using Tableau parameters and calculated fields to switch between Profit & Loss (P&L), Balance Sheet, and Cash Flow visualizations.

- **Financial Dashboard Design:** Learned how synchronized financial tables and trend charts, selective data labels, and clean layouts can improve the readability and presentation of financial information.

- **Data Preparation for Business Intelligence:** Developed an understanding of how financial statement data can be structured and transformed for multi-year analysis and visualization in Tableau.
